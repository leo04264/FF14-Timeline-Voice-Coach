# M7S H1 占星術師影片奶軸

適用檔案：`public/timelines/m7s-h1-astrologian.json`，版本 `0.2.0`。

## 依據與對齊方式

- 主要依據：[Nephritesssss 的 M5S–M8S 占星奶軸影片，第 3 分 P（M7S）](https://www.bilibili.com/video/BV1XZ5FzCEdb?p=3)。使用片頭配置表及各段治療說明。
- 輔助依據：[作者附的 Stella M7S 減傷／治療表](https://docs.qq.com/sheet/DRXhURUdsSVRDQ3Vs?tab=BB08J2)。表格將技能寫在它負責的傷害列，不一定代表實際按鍵時間。附表和影片有不同配置時，以影片為主，例如 P3 的大宇宙留給鋼鐵／月環接大團傷，不照抄附表另一個不足 180 秒的施放點。
- 技能冷卻與有效時間對照：[官方占星術師職業指南](https://na.finalfantasyxiv.com/jobguide/astrologian/)。這是現行指南，影片本身為 7.2；本次未將現行威力數值套用成治療量或存活率計算。

JSON 的零秒是戰鬥開始，不是影片零秒。保留原本 40 筆 Boss 機制的時間，只按機制安排可執行的預放、施放與引爆時間；不是逐幀複製影片的全部按鍵。部分 Boss 語音預告有前後錯開，傷害落點沒有移動。

## 輔助提醒與限制

- 保留占卜 11.5／131.5／251.5／371.5／491.5／611.5 秒的 120 秒節奏。六分鐘窗在 Boss 回場後；這是本工具的輸出輔助設定，不宣稱是影片每次按鍵的重現，仍須與實際隊伍協調。
- 約 30 秒提醒檢查焚灼，密集處合併短句或小幅錯開，快到期才補。轉場不可選取期間不要求占卜／補毒；提醒時刻不等於強制施放時刻。
- 貴婦全部為條件式提醒。沒有王冠之淑女時改用陽星合相，不假設每個提醒點都有免費貴婦；本檔未固定或模擬完整抽卡軸。
- 光速的最後冰花提醒依自己實際放冰花的輪次使用。擢升、交錯及卜卦也須依點名與坦血量調整。
- 此次驗證不包含魔力、完整 GCD／插入技隊列、治療量、搭檔減傷、網路延遲或語音引擎的實際句長。2 秒碰撞檢查通過，不等於所有語速下都不會語音排隊，也不等於實戰一定存活。
- 本次只替換內建範例。使用者先前另存的自訂副本不會被覆蓋；需要重新從內建範例建立副本。
