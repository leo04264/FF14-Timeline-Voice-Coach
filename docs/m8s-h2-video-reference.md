# M8S H2 學者：影片奶軸 v0.3.0

適用 [`public/timelines/m8s-h2-scholar.json`](../public/timelines/m8s-h2-scholar.json)。選 **H2／學者**，倒數至少 **10 秒**，先召喚仙女。

v0.2.0 的影片一致性有問題：起手操作缺漏、部分治療早於機制判定、部分大仙女時間排早，以及將未出現的狂暴傷害當作校時點。v0.3.0 重新核對全片 75 段戰鬥字幕，並以可辨識的標記、傷害、擊退和仙女量譜核對關鍵時間窗。舊版測試通過不足以證明內容正確。

## 來源與精度

- [野生西瓜 M8S 學者講解影片](https://www.bilibili.com/video/BV1Vc3Nz7Ejd)，2025-06-30，7.2 版本。
- [官方學者 PvE 指南](https://na.finalfantasyxiv.com/jobguide/scholar/)：核對冷卻、持續時間及技能互斥。現行指南與影片版本不同，不以現行威力推算影片治療量。
- [cactbot R8S 原始軸](https://github.com/OverlayPlugin/cactbot/blob/main/ui/raidboss/data/07-dt/raid/r8s.txt)僅協助辨認機制；不能把其中的同步用人工座標直接當整場時間，也不能將讀條結束一律當成畫面傷害落點。
- [完整盤點與差異](m8s-h2-video-audit.md)、[機器可讀證據與操作索引](m8s-h2-video-audit.json)。

關閉登入提示後可繼續觀看，但可取得的畫面仍為 **640×360**。字幕全片以每秒一幀盤點，再核對相關畫面；重要邊界另用細分畫面確認。**不是每一個按鍵的逐幀紀錄，也不是伺服器戰鬥 log。** 機制觀察通常只有約 ±0.5–1 秒精度；JSON 小數表示排程位置，不代表毫秒級證據。字幕可能提前講解，也可能延續至動作之後，因此技能依「傷害後／標記出現／仙女回場」等條件執行，不能把字幕第一幀直接當按鍵時間。

多技能同一列是順序提示，例如「轉化→上毒→藥」，不是要求同時按完。預盾列預留增益與讀條時間，展開另外排在盾完成後。實際血量、量譜、剩餘毒、CD 與隊友減傷仍須玩家判斷。

本版零點為影片 **00:21.5** 左右的交戰畫面；21.4–21.5 秒選取環由黃轉紅，這不是伺服器開戰封包時間。

雙狼後與後半可選取時，依隊伍進度手動校時。播放器不會自動偵測遊戲、擊殺速度或 CD。移動剩餘時間軸不會讓技能立即冷卻；若與這場影片的轉場時間不同，需一併檢查跨階段技能。

影片在狂暴長讀條中擊殺，**沒有狂暴傷害畫面**。本版僅提示狂暴讀條與輸出。較慢隊伍若前半多打一輪空間斬，需增補前半治療及重新設定後半起點。

## 語音與輸出提醒

預設只開學者軌：**136 個操作／檢查事件、134 句語音**。2 個相鄰操作的語音併入前一列，但保留各自的操作時間及完整名稱。56 個王機制保留為可選參考軌，預告最多提前 3 秒。兩軌一起開會有碰撞提示，不會再把王預告移到十多秒以前。

**既有瀏覽器可能保留舊版兩軌全開的選擇**，請在播放器確認只選「H2 學者｜影片治療＋連環計＋到期補毒」。自行另存的副本不會被內建更新覆蓋，需要重新從內建軸建立副本。

連環計保留全部七輪，按影片團輔段落安排；不是所有隊伍通用的唯一爆發軸。後半起手只重上毒，不重開連環計。

## 可選治療與資源

- 影片中的「低語／祥光」、「秘策不屈／群盾」是選項，不是一律全按。本版第一次空間斬後選低語，千年風化後選祥光；終盤首輪八連選秘策不屈。
- 前半收尾選普通群盾，把秘策留給後半起手。雙重暴風低血坦選活性；此時上一個深謀尚未轉好。名稱仍保留選擇原因。
- 雙狼第三輪先不屈，祥光等熾天使結束、仙女回場再用。所有六組大仙女均保留兩段慰藉，轉化期間不安排仙女技能。
- 以太超流檢查是工具補充：就緒且豆花完才補；至少保留當段的罩子與必要治療豆。能量吸收只用餘豆。終盤第二平台依影片先打完豆再轉化，本版選轉化後打兩豆、留一豆給可選綠帽；最後平台另提醒超流接罩子，避免把豆全打掉後無法治療。
- 仙女連線須有量譜；影片的「右側／出生台／雙奶台」沿用其 H2 分組，需與隊伍站位一致。雙坦單盾、綠帽及低血追加治療均有條件，沒有用固定秒數取代血量判斷。

## 驗證與部署

```sh
npm test -- src/timeline/builtinM8sScholar.test.ts
npm test
npm run build
git diff --check
```

專用測試使用字幕索引、機制觀察區間、仙女量譜切換以及傷害前後的相對條件，另外檢查技能冷卻、兩段慰藉、仙女互斥、附體期間、擴散盾覆蓋、保守治療豆預算及完整播放計畫。預設學者軌在 2000ms 檢查窗沒有碰撞；合開王軌會如實警告。這仍不等於遊戲內治療量、仙女施法延遲、MP、完整 GCD／插入技或每個瀏覽器 TTS 音速都已實測。

部署走 `master` 的 GitHub Pages workflow（測試、建置、發布）。修改範圍僅此內建軸、證據文件與專用測試。需回滾時 revert 修正 PR，再由同一 workflow 部署；回滾版本是已知有內容誤差的 v0.2.0，不能把回滾當成內容驗證通過。
