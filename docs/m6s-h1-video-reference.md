# M6S H1 占星術師：影片對照與改版說明

本次更新兩個既有內建範例，保留各自的檔名、ID 與 H1／AST 對象：

- `public/timelines/m6s-h1-astrologian.json`：`0.4.0`，影片完整奶軸，另有條件式單補與第二輪塔補強。
- `public/timelines/m6s-h1-astrologian-core.json`：`0.2.0`，影片核心奶軸及補毒／爆發提醒，省略上述額外補強。

## 來源與範圍

- 主要依據：[Nephritesssss 的 M5S–M8S 占星奶軸影片，第 2 分 P（M6S）](https://www.bilibili.com/video/BV1XZ5FzCEdb?p=2)。直接核對片頭占星配置表及片中說明，沒有以學者搭檔表代替占星配置。
- 王機制時間基準：[cactbot 的 M6S 原始時間軸](https://github.com/OverlayPlugin/cactbot/blob/main/ui/raidboss/data/07-dt/raid/r6s.txt)，於 2026-09-08 核對。沿用原 Core 範例的 45 筆機制事件，完整版本亦改用同一份基準；只在本次兩個 H1 檔案中同步，不改動 H2 學者或通用 M6S 範例。河流之後的上游資料仍有待整理註記，不將其當作每場實戰都精確一致的保證。
- 冷卻、充能與持續時間核對：[官方占星術師職業指南](https://na.finalfantasyxiv.com/jobguide/astrologian/)。現行指南與 7.2 影片的版本不同，本次只核對相關技能規則，不套用現行威力計算治療量。

影片有片頭與倒數，播放秒數不是戰鬥秒數；以下表格全部使用 JSON 的戰鬥秒數。動物園擊殺速度與隊伍打法也會造成偏移。此工具沒有遊戲資料自動同步，使用前須以自己隊伍的戰鬥校準。

## 補毒與爆發

- 補毒固定在 `0、30、60 … 660 秒`，共 23 次，實際語音觸發時間也維持每 30 秒。內容是檢查焚灼剩餘時間，將到期且有可選取目標才補，不強迫提早覆蓋。
- 動物園的定期提醒使用「有目標才補毒，換怪重補」，另在第一波小怪可選取後的 229.5 秒加目標切換提醒。不把整段動物園當成停止輸出，也不假設小怪死亡或 Boss 無法選取時仍可施放。
- 占卜採下述日服野團「轉好即開」版，共 6 次，固定間隔 120 秒。保留原先秒數，但在事件、階段與語音中明確區分開場及動物園 W4 爆發，不再只顯示通用的「每 120 秒爆發」。
- 為避免語音衝突，只合併相容的治療操作並調整王機制預告，不改動上述固定提醒週期，也不關閉提示來掩蓋碰撞。

### 野團爆發版本的核對

於 2026-09-08 核對到兩種不同安排，不能說所有野團都共用唯一的爆發秒數：

- [XIV JP Raids 的 M6S 日服宏](https://xivjpraids.com/7.0_dawntrail/savage_raids/m6s/)在小怪段指定「リキャバースト」，即團輔轉好就開，W1 也註明同樣做法。影片作者的介紹明示全系列為日服野團錄製，因此本範例採這個版本。
- [Kitten ERP Guides 的 Soul Sugar 攻略](https://kitten-erp-guides.moe/savage/m6s/soul_sugar)另介紹 W2 魚連線確認、集怪後再交兩分鐘爆發，並在 W4 後段清松鼠／羊時再開一次；該站描述延後版在其 PF 環境較普遍。這與前述日服宏不同，不把延後 W2 的第一輪和轉好即開版的第二輪混用。

本工具的具體提醒如下；**12 秒起手及下表秒數是本範例的排程，不是上述攻略指定的全野團統一秒數，也不是影片的逐次施放紀錄。**

| 戰鬥時間 | 爆發位置 | 語音 |
| --- | --- | --- |
| 00:12 | 開場 | 開場爆發，占卜出牌 |
| 02:12 | 沙漠階段 | 兩分爆發，占卜出牌 |
| 04:12 | 動物園 W1 尾段，20 秒團輔涵蓋 W2 開頭 | 一波尾，占卜出牌 |
| 06:12 | 動物園 W4 後半 | 四波爆發，占卜出牌 |
| 08:12 | 雷雲階段 | 八分爆發，占卜出牌 |
| 10:12 | 終盤 | 十分爆發，占卜出牌 |

依共用王軸，W1 約在 03:47.4 出怪、W2 在 04:16.5 出怪；W4 約在 05:17.7 出怪，第二次隕石在 06:28.7。因此「開場與 W4 都有爆發」在此版本成立，但 W4 的占卜是 **06:12 的後半爆發，不是 05:17.7 剛出怪就開**。若 04:12 已用占卜，W4 出怪時才過 65.7 秒，尚未符合官方 120 秒冷卻，不能再加一發。

進組仍須確認招募／宏是轉好即開還是 W2 延後版。若隊伍改採 W2 延後或實際施放有延遲，後續每次占卜也須重新校正，至少間隔 120 秒並重跑語音碰撞檢查；本工具不會讀取遊戲內團輔或冷卻自動改軸。

## 限制與驗證

貴婦皆是條件式提示：有王冠之淑女才用，沒有就依血量改陽星合相。完整版本的額外單補及第二輪塔天宮圖是工具補強，不冒充影片逐次按鍵。測試沒有模擬完整抽卡、魔力、搭檔減傷、GCD／插入技佇列、裝等與實際治療量，不代表每種隊伍都能照抄存活。

靜態檢查包含兩份的結構／領域規則、冷卻與依序充能、11 組地星、完整版本 6 組／核心版本 5 組強化天宮圖、3 組大／小宇宙、5 組中間學派／太陽星座及群盾延續。太陽星座可用期是中間學派提供的 30 秒，不應誤當成 20 秒本體增益。

全部提示保持啟用；預設 2000ms 碰撞視窗為 0，各語音觸發點至少相隔 2100ms。這不代表所有語速下都不會排隊，實際播報仍應試聽。
